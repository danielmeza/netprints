# NetPrints API reference

Generated from the XML documentation comments of the packable libraries:

- **NetPrints.Core** — the graph model: nodes, pins, connections, projects.
- **NetPrints.Reflection** — reflection-backed method and type discovery used by the graph editor and code generator.

Adding a library to this reference is one line in `docs/api/docfx.json` (`metadata[0].src[0].files`).

See the [NetPrints documentation site](https://danielmeza.github.io/netprints/) for guides, the
release process and design decisions.
