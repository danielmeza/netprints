# XAML and UI rules

This file holds no rule of its own. The rules live in one place, listed here by path. Load them before editing
`.axaml`, views, styles, converters or behaviors in `NetPrints.Editor` or `NetPrints.Desktop`:

- `AGENTS.md`, section "XAML and UI".
- `.claude/skills/avalonia-xaml/SKILL.md`: views, bindings, templates, lists, dialogs, accessibility.
- `.claude/skills/avalonia-styling/SKILL.md`: colors, brushes, styles, themes, converters.
- `.claude/skills/avalonia-behaviors/SKILL.md`: shortcuts, focus, drag and drop, closing dialogs, scrolling.

Do not copy the skills into this folder.
