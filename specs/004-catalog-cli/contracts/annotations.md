# Contract: `NetPrints.Annotations` (P2)

Implements FR-025–FR-031 (ADR-0014). Source: `src/NetPrints.Annotations/` (+ shared files linked from
`src/NetPrints.Catalog/`). Tests: `tests/NetPrints.Catalog.Tests/Generator/`, `tests/NetPrints.Catalog.Tests/EndToEnd/`,
`tests/NetPrints.Editor.Tests/Reflection/`.

## 2. Injected attributes (post-initialization output, namespace `NetPrints.Annotations`)

All `internal sealed` and `[global::Microsoft.CodeAnalysis.Embedded]`. None is `[Conditional]`: the marker
attributes stay in metadata so the tool flavor reads the same annotations from a compiled assembly (parity), and
`NetPrintsEmbeddedCatalogAttribute` is what discovery reads.

```csharp
[AttributeUsage(AttributeTargets.Assembly, AllowMultiple = true)]
internal sealed class NetPrintsCatalogAttribute(string assemblyName) : Attribute
{
    public string AssemblyName { get; } = assemblyName;
    public string? Id { get; set; }          // default: assembly simple name, lower-cased
    public string? Profile { get; set; }     // built-in id or the file name of an AdditionalFiles *.npprofile.json; default public-api
    public string[]? Include { get; set; }
    public string[]? Exclude { get; set; }
    public string? AccessorName { get; set; } // default: PascalCase of Id
}

[AttributeUsage(AttributeTargets.Class | AttributeTargets.Struct | AttributeTargets.Interface | AttributeTargets.Enum)]
internal sealed class NetPrintsTypeAttribute : Attribute
{
    public string? DisplayName { get; set; }
    public string? Category { get; set; }
}

[AttributeUsage(AttributeTargets.Method)]
internal sealed class NetPrintsNodeAttribute : Attribute
{
    public string? DisplayName { get; set; }
    public string? Category { get; set; }
    public string[]? Keywords { get; set; }
}

[AttributeUsage(AttributeTargets.All & ~AttributeTargets.Assembly)]
internal sealed class NetPrintsIgnoreAttribute : Attribute { }

[AttributeUsage(AttributeTargets.Assembly, AllowMultiple = true)]
internal sealed class NetPrintsEmbeddedCatalogAttribute(string id, int schemaVersion, string json) : Attribute
{
    public string Id { get; } = id;
    public int SchemaVersion { get; } = schemaVersion;
    public string Json { get; } = json;
}
```

(Primary constructors and `?` shown for brevity. The injected and generated sources compile at C# 7.3: classic
constructors, no `?` annotations on reference types and no `#nullable` directive.)

## 3. Generator behaviour (`CatalogGenerator : IIncrementalGenerator`)

1. **Own annotated symbols** (`ForAttributeWithMetadataName` on `NetPrintsTypeAttribute`, `NetPrintsNodeAttribute`):
   when any exist, emit one catalog with id = the compilation's assembly name lower-cased, version = its assembly
   version, profile `annotated`, covering the compilation's own assembly. Hint name `NetPrintsCatalog.Self.g.cs`.
2. **Referenced assemblies** (each `[assembly: NetPrintsCatalog]`): find the referenced `IAssemblySymbol` by simple
   name (NPC001 if absent); resolve the profile (built-in or an `AdditionalFiles` item whose file name equals the
   `Profile` value, NPC002/NPC003); apply `Include`/`Exclude`; build with the shared engine over a private
   compilation of the metadata references; documentation from `AdditionalFiles` with metadata
   `NetPrintsReferenceDocumentation=true` whose file name matches `<AssemblyName>.xml`. Emit the embedded attribute
   and the `NetPrintsCatalogs.<AccessorName>` accessors in the project's root namespace (`build_property.RootNamespace`).
   Hint name `NetPrintsCatalog.<Id>.g.cs`.
3. Duplicate ids in one compilation → NPC006, neither emitted. Two catalogs whose accessor names are equal (an explicit
   `AccessorName`, or the same derived name such as `my-lib` and `my.lib`) are NPC006 as well, and neither is emitted.
4. Output is deterministic and independent of syntax-tree and reference order.

Emitted file (`EmbeddedCatalogEmitter`; example for a request with `AccessorName = "CatalogFixtureLib"`, the byte lists are cut):

```csharp
// <auto-generated/> NetPrints.Annotations
[assembly: global::NetPrints.Annotations.NetPrintsEmbeddedCatalogAttribute("catalogfixturelib", 1, "{\n  \"$schema\": …}\n")]

namespace MyProject
{
    internal static partial class NetPrintsCatalogs
    {
        public static byte[] CatalogFixtureLibUtf8 { get; } = new byte[]
        {
            123, 10, 32, …
        };

        public static string CatalogFixtureLib => global::System.Text.Encoding.UTF8.GetString(CatalogFixtureLibUtf8);
    }
}
```

- The file compiles at C# 7.3: block-scoped namespace, no `const string`, no `u8` literals (D-R3, contracts/catalog.md §4).
  The attribute argument is a metadata blob (UTF-8), not the user string heap, so it does not count against CS8103;
  the accessor is a `byte[]` initializer (raw data) plus a string property that decodes it on each access.
- With no `RootNamespace` (or an invalid one) the class is in the global namespace.
- The accessor name is `AccessorName` when set, else the PascalCase of the id (`my-lib.core` is `MyLibCore`).
- Diagnostics NPC001 to NPC003 and NPC006 fail the affected catalog only; an invalid explicit `Id` or `AccessorName` is reported as NPC003.
- The own catalog is built from the parsed documentation comments of the sources. When the compilation does not parse them
  (`DocumentationMode.None`, that is, no `GenerateDocumentationFile`), the catalog is still emitted and NPC007 warns.
- Documentation files of references are read only for the assemblies a request names, inside the referenced step, so a
  compilation without a request never reads them.
- Pipeline steps carry tracking names `OwnCatalog`, `ReferencedCatalog` and `CatalogOutputs`; their models are
  equatable (no symbols or compilations), so editing an unrelated syntax tree leaves the referenced step cached (AN-T07).

## 4. Diagnostics

`NPC001`–`NPC007` as in contracts/catalog.md §3, as `DiagnosticDescriptor`s with category `NetPrints.Catalog`,
help link `https://danielmeza.github.io/netprints/guide/catalogs#diagnostics` (the docs site serves `docs/` at its root, so
there is no `/docs/` segment; `DiagnosticsTests` maps the link to `docs/guide/catalogs.md` and its `## Diagnostics` heading), tracked in
`src/NetPrints.Annotations/AnalyzerReleases.Unshipped.md`.

## 5. Build targets (`build/NetPrints.Annotations.targets`)

```xml
<ItemGroup>
  <CompilerVisibleItemMetadata Include="AdditionalFiles" MetadataName="NetPrintsReferenceDocumentation" />
  <CompilerVisibleProperty Include="RootNamespace" />
</ItemGroup>
<Target Name="NetPrintsAddReferenceDocumentation" AfterTargets="ResolveAssemblyReferences" BeforeTargets="CoreCompile">
  <ItemGroup>
    <_NetPrintsReferenceXml Include="@(ReferencePath->'%(RootDir)%(Directory)%(Filename).xml')"
                            Condition="'%(ReferencePath.FrameworkReferenceName)' == '' or '$(NetPrintsCatalogFrameworkDocumentation)' == 'true'" />
    <AdditionalFiles Include="@(_NetPrintsReferenceXml)" Condition="Exists('%(FullPath)')" NetPrintsReferenceDocumentation="true" />
  </ItemGroup>
</Target>
```

## 6. Discovery in the editor

`ReflectionHost` (`src/NetPrints.Editor/Hosting/ReflectionHost.cs`): `catalogs = registry.TypeCatalogs` followed by
`EmbeddedCatalogReader.Read(reference.Path)` for each
`snapshot.References` entry (loaded with
`CatalogLoader.Load`); first id wins (NPC103 logged); covered assemblies are excluded from the live provider as in
P1.
